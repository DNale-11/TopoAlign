Web interface availability
==========================

The public TopoAlign 0.1.0 source revision documented here does not contain a
``webapp`` directory or a Web server entry point. Earlier documentation included
Web screenshots and commands such as ``python webapp/backend.py``; those
instructions cannot be followed from this public checkout.

For visual interaction, use the :doc:`napari_guide`. For reproducible commands
and one-Fixed-to-many-Moving processing, use the :doc:`cli_guide`. The optional
CLI Agent is described in :doc:`agent_guide`.

This page retains the previous documentation URL so that older links explain
which supported workflow to use.
