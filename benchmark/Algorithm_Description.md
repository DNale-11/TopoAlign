# 细胞配准算法流程详解 (适用于论文方法部分)

本研究提出的细胞配准算法采用了一种多阶段的混合配准框架。该框架结合了基于深度学习的形态学分割、鲁棒的点集特征匹配以及基于频域强度的亚像素级联合优化。具体的配准流程（将另一轮次的移动图像配准至参考图像）包含以下七个核心步骤：

## 1. 基于深度学习的细胞实例分割 (Cellpose Segmentation)
针对多轮独立成像数据，算法首先调用 Cellpose 深度学习通用细胞分割模型，独立获取源图像（Source Image）和参考图像（Reference Image）的细胞掩码（Mask）。在荧光成像由于背景噪声强弱不一、亮度漂移的情况下，直接使用像素强度进行配准极易因局部最优而失败。因此，引入实例分割步骤，我们将连续的像素空间抽象为高稳定性的离散细胞空间。

## 2. 形态学与空间特征提取 (Feature Extraction)
基于分割获得的细胞掩码，算法分别计算源图像与参考图像中每一个细胞个体的几何空间特征。提取的核心特征为细胞的二维空间质心坐标（Centroids），同时计算其他基本形态属性（如细胞面积大小）。该步骤将两幅原始图像成功转化为了两组纯几何点集（Point Sets），为后续的拓扑匹配奠定了基石。

## 3. 从粗到精的二阶段特征匹配与校验 (Two-Stage Coarse-to-Fine Matching)
为了在数量庞大的细胞点集中快速且准确地建立对应点对，算法采用了一套二阶段匹配加严格阈值校验的策略：
- **初步粗匹配 (Coarse Matching):** 利用较为宽松的距离阈值或者局部拓扑相似性，快速获取初步点对，并同时估算出两幅图像间的粗平移量。
- **精匹配与置信度校验 (Fine Matching & Validation):** 将搜索限定在一定大小的空间窗口（Spatial Window）内，并加入空间距离的权重系数进行评分。随后引入严格的置信度下限（Min Confidence）和特征差异上限（Max Feature Diff）进行复验，从而剔除因由于组织变形或者细胞缺失/新生造成的误匹配。

## 4. 基于 RANSAC 的鲁棒变换估计与引导重采 (Robust Transform Estimation & Guided Rematch)
获得高信噪比的特征点对后，下一步为推导图像发生漂移和形变的全局空间坐标转换矩阵：
- **RANSAC 仿射变换估计:** 采用随机抽样一致性算法（RANSAC）鲁棒地拟合出两者间的全局仿射变换矩阵（Affine Transform）。RANSAC 通过迭代抽取极小点子集对模型进行假设和验证，能够极大程度地抵御残余离群点（Outliers）造成的扰动。
- **自动降级机制:** 面对低质量切片产生的罕见极少匹配对情况，算法会自动触发降级保护，即采用未知数更少的相似变换（Similarity Transform）甚至单纯的质心中位数平移（Translation）来代替仿射矩阵，确保了管线的极高容错率。
- **引导式二次重匹配:** 算法预先应用首次拟合的变换矩阵将源特征强行投影至参考空间，对校正后的坐标再次发起精准贪婪匹配（Greedy Match）。将二次挖掘获得的点对纳入重新拟合，若得到的 RANSAC 新得分取得提升，则直接更新最优变换矩阵。

## 5. 基于 K 近邻 (KNN) 的局部结构平滑与调优
为进一步保障细胞的相对空间结构关系不受跨轮次配准污染，算法执行一次基于点对 KNN 邻域的局部迭代优化。该步骤通过分析验证各个点对其局部 K 个邻居的位移一致性，对变换模型施加正则化约束（严格约束最大旋转角度、最大相对平移量及过度缩放操作）。在此基础上执行一轮“只优化平移向量（Optimize Translation Only）”的操作以防止因过度拟合诱发无物理意义的人工剪切拉伸变形。

## 6. 基于相位相关（FFT）的亚像素级强度精调
基于点云特征的配准在解决大位移上极为优异，但其精度天然存在基于分割准确性的“天花板”。为了突破达到亚像素级的刚硬配准极限，本算法在管线最末端集成了基于像素强度的互相关调优（Phase Cross-Correlation）。利用已获取的特征变换矩阵将图像进行粗略对齐后，算法从它们重叠区域截取视场并使用快速傅里叶变换（FFT），随后在频域引入 20 倍上采样（Upsample Factor = 20），以极高的计算效率定位出交叉功率谱中的相位相关尖峰，并借此解算出最后几微米（像素）的微小漂移量。

## 7. 图像扭曲重采样与插值 (Image Warping)
最后阶段为应用上述所有的形变参数对原始图像进行插值与重写。系统把 RANSAC 全局拓扑仿射矩阵与 FFT 亚像素平移等效为一个完整的逆向映射字典。以参考图像物理尺寸为最终输出边框，借助双线性插值或高阶样条插值算法逆向拉取原始切片像素，并在全过程中严格保证原有像素密度与信号强度的动态区间范围，完成全自动高精度配准图像闭环输出。
